# 🤖 AI Resume Screening & Job Recommendation System

An AI-powered Resume Screening and Job Recommendation System that automatically analyzes resumes, extracts candidate information using NLP techniques, matches skills with job requirements, ranks suitable job opportunities, and generates a detailed resume analysis report.

---

# 📌 Project Overview

Recruiters spend a lot of time manually reviewing resumes. This project automates the initial screening process using Natural Language Processing and Machine Learning techniques.

The system:

- Uploads resumes in PDF/DOCX format
- Extracts important candidate information
- Identifies skills, education, and projects
- Compares candidate profiles with job descriptions
- Generates job recommendations with match scores
- Creates an automated PDF resume analysis report

---

# ✨ Features

## 📄 Resume Processing

✅ PDF resume parsing

## 🧠 NLP Based Information Extraction

Extracts:

- Email

- Technical Skills
- Education
- Projects

## 🔍 AI Job Matching

The system analyzes:

- Candidate skills

- Job requirements

and generates ranked job recommendations.
